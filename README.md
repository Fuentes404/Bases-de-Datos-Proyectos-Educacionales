# 📊 Proyectos Educacionales - Bases de Datos

Repositorio académico que documenta el trabajo práctico desarrollado durante la asignatura de **Modelamiento de Bases de Datos** (Duoc UC).
Incluye ejercicios, modelos y entregables organizados semanalmente, abarcando desde el diseño conceptual (MER) hasta la normalización y la generación del Modelo Relacional (MR) con su script DDL.

## 📚 Contenido del repositorio

| Semana | Tema / Aplicación | Uso | Acceso directo |
|---|---|---|---|
| Semana 1 | Construyendo una base de datos | Primer acercamiento al modelado: levantamiento y análisis de requerimientos iniciales para el diseño de una base de datos | [📁 Ver carpeta](./Semana-01-Construyendo-una-base-de-datos) |
| Semana 2 | Modelo Entidad-Relación (MER) — Caso aerolínea *BT&Airways* | Diseño del MER en notación Barker y su modelo relacional/físico (Bachman) usando **Oracle SQL Developer Data Modeler**; incluye jerarquía supertipo/subtipo (`EMPLEADO` → `ADMINISTRATIVO` / `PILOTO`) | [📁 Ver carpeta](./Semana-02-Modelo-Entidad-Relacion) |
| Semana 3 | Jerarquía entre entidades | Modelamiento de relaciones de herencia (supertipo/subtipo) entre entidades del negocio | [📁 Ver carpeta](./Semana-03-Jerarquía-entre-entidades) |
| Semana 4 | Normalización — Caso *Ministerio del Trabajo* | Aplicación de formas normales para transformar un modelo lógico en un modelo relacional normalizado | [📁 Ver carpeta](./Semana-04-Normalizacion) |
| Semana 5 | MER y MR — Caso retail *Solari S.A.* | Transformación de un MER conceptual sin normalizar en un MER-E Normalizado, derivación del Modelo Relacional (MR) y generación del **script DDL** en Oracle SQL | [📁 Ver carpeta](./Semana-05-MER-y-MR) |
| Semana 6 | Implementando un Modelo Relacional con Sentencias SQL — Caso *Consultorio Médico Santa Gema* | Completado de un modelo relacional entregado incompleto y su implementación física en Oracle Database mediante **script DDL**: creación de tablas, llaves primarias y foráneas, restricciones (`CHECK`, `UNIQUE`, `IDENTITY`) y modificaciones posteriores con `ALTER TABLE` | [📁 Ver carpeta](./Semana-06-El-Modelo-Relacional-y-las-Sentencias-SQL) |

## 🛠️ Software y herramientas de desarrollo

- **Oracle SQL Developer** — gestión y consulta de bases de datos
- **Oracle SQL Developer Data Modeler** — diseño y modelamiento de datos (MER, MR, DDL)
- **Oracle Database 11g** — motor de base de datos objetivo de los scripts DDL
- **JDK:** Java Development Kit 17 o superior
- **Control de versiones:** Git
- **Plataforma:** GitHub

## 🎯 Objetivo

Este repositorio busca centralizar el proceso de aprendizaje del modelamiento de bases de datos, sirviendo como respaldo del avance semanal y como material de referencia para futuras consultas.
